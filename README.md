# 🛒 Online Tech Store (Fullstack Web Application)
 React + TypeScript + Vite

 
Полнофункциональный интернет-магазин техники с админ-панелью, фильтрацией товаров, корзиной и ролевой системой доступа.

 # Посмотреть сайт на Vercel
🚀  [Посмотреть проект вживую (Live Demo)](https://device-shop-mobx.vercel.app) 


## 🛠 Стек технологий
### Frontend:
- **React 19** + **TypeScript**
- **Vite** (быстрый сборщик)
- **MobX** (управление глобальным состоянием)
- **Ant Design** (UI-компоненты и стилизация)
- **React Router** (клиентская маршрутизация)
- **Axios** (работа с API и интерцепторы)
### Backend:
- **Node.js** + **Express**
- **PostgreSQL** (реляционная база данных)
- **Sequelize ORM** (модели и связи данных)
- **JWT (JSON Web Token)** + **bcrypt** (безопасная аутентификация)
- **express-fileupload** (загрузка медиафайлов)
---

## ✨ Основной функционал
- 🔐 **Авторизация и роли**: Регистрация, вход, хранение сессии по токену, разделение прав (`USER` / `ADMIN`).
- 📱 **Каталог устройств**: Фильтрация по брендам и типам, пагинация, детальная страница каждого товара с характеристиками.
- 🛒 **Корзина покупок**: Добавление/удаление товаров, расчет общей стоимости заказа.
- ⚙️ **Панель администратора**: Создание новых категорий, брендов и товаров с динамическими характеристиками и фото.
- 📱 **Адаптивный дизайн**: Корректное отображение на смартфонах, планшетах и мониторах.
